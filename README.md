### InferMatrix

**A behavior analysis framework for Agentic LLM systems.**

`Case` → `Run` → `Raw Response` → `Parse` → `Validate` → `Report`

</div>

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>Why it exists</h3>
      <p>
        “OpenAI-compatible” endpoints often share a request format but differ in
        streaming, tool calls, structured output and edge-case behavior.
        InferMatrix turns those differences into reproducible evidence.
      </p>
    </td>
    <td width="50%" valign="top">
      <h3>What is already built</h3>
      <p>
        ✅ Typed YAML cases & CLI<br />
        ✅ Mock OpenAI-compatible backend<br />
        ✅ Response normalization<br />
        ✅ Runner & streaming cases<br />
        ✅ Structured tool-call parsing
      </p>
    </td>
  </tr>
</table>
