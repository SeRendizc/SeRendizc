## 🚀 Featured Project

### [InferMatrix](https://github.com/SeRendizc/infer-matrix)

> A behavior analysis framework for Agentic LLM systems.

InferMatrix focuses on the interface layer where **OpenAI-compatible serving**, **streaming responses**, **structured outputs**, and **tool calling** interact.

```text
YAML Case  →  Runner  →  Raw Response  →  Parser  →  Validation  →  Report
```

Currently implemented:

- ✅ Typed YAML cases and CLI workflow
- ✅ Mock OpenAI-compatible backend
- ✅ Chat-completion response normalization
- ✅ Repeatable runner and streaming cases
- ✅ Structured tool-call parsing

Next direction: **JSON Schema validation → reports → real endpoint adapters → vLLM / SGLang behavior analysis**.
